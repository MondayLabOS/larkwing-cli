# Teacher Agent 与日常模板实施计划

## 目标

让第一次使用 `larkwing`、或者暂时说不清目标的用户，也能在一次调用内找到一个可以马上执行的入口；同时补齐不依赖远程 Wiki 的日常工作模板。

## Teacher Agent 交互原则

1. 不先问“你的目标是什么”，先问“最近最想省时间的是哪类事情”。
2. 先利用用户已经给出的场景线索，再判断是否真的没有目标。
3. 一次最多推荐四个入口，每个入口说明用途并给出可复制命令。
4. 信息不足时只追问期望产出：文档、清单、计划或行动项。
5. 默认 dry-run，Teacher 不替用户执行会产生远程写入的操作。
6. `--json` 返回稳定的 `status`、`message`、`question` 和 `suggestions`，便于上层 Agent 继续多轮对话。

## CLI 接入点

| 入口 | 行为 |
| --- | --- |
| `larkwing` | 进入无目标引导 |
| `larkwing teacher [描述]` | 根据场景给建议 |
| 未匹配的自然语言 | 回退到 Teacher，不抛出匹配错误 |
| 已匹配工作流或模板 | 继续原有 dry-run / execute 流程 |

## 本期模板

首批选择高频、跨团队、填写成本低的十个场景：周计划、每日同步、会议决策、客户拜访、项目进度、轻量复盘、新人带教、内容发布、费用报销、工作交接。

这些模板采用 `local-document` 交付方式：

1. 从 catalog 读取内容和可选输入。
2. 在 `.larkwing/runs/` 渲染 Markdown artifact。
3. 默认只预览命令。
4. 用户加 `--execute` 后，通过 `lark-cli docs +create` 创建飞书文档。

原有远程模板保持 `wiki-copy` 行为；统一入口 `template use` 根据模板类型自动选择交付方式。
